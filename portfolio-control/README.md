# מרכז הבקרה להשקעות

דשבורד שמתעדכן לבד. השרת של GitHub מושך מחירים כל 10 דקות בשעות המסחר בארה״ב, ומחשב בכל פעם:
- ATR(14), ממוצעים נעים של 50 ו־200 יום, ו־RSI
- תאריכי דוחות קרובים
- מצב השוק (כלל M של אוניל)
- המרחק של כל סטופ ביחידות ATR
- סטופ מוצע לפי השיטה

האתר הוא קובץ סטטי ב־GitHub Pages. כל הנתונים מוצפנים ב־AES‑256, והם נפתחים רק בדפדפן ורק עם הסיסמה.

## איך זה בנוי
- `data/portfolio.enc` — האחזקות, הפקודות, רשימת המעקב והמכירות. מוצפן במפתח `DATA_KEY`. הקובץ הגלוי `data/portfolio.json` לא נשמר בריפו (מוגדר ב־`.gitignore`).
- `scripts/update.py` — רץ בשרת: מפענח את התיק, מושך מחירים מ־Finnhub והיסטוריה מ־Yahoo, מחשב, ומצפין את התוצאה ל־`site/data.enc.json` עם הסיסמה `DASH_PASS`.
- `site/index.html` — הדשבורד. שואל סיסמה, מפענח בדפדפן, ונטען מחדש כל 2 דקות.
- `.github/workflows/update.yml` — מריץ את העדכון ומפרסם ל־Pages:
  - כל 10 דקות, 13:00–21:59 UTC, ימים א'–ה'
  - פעם אחת אחרי הסגירה
  - פעם ביום, כדי שהתזמון לא יכבה

## סודות (Settings → Secrets and variables → Actions)
| שם | מה זה | מי מגדיר |
|---|---|---|
| `FINNHUB_KEY` | מפתח ה־API של Finnhub | יניב |
| `DASH_PASS` | הסיסמה לפתיחת הדשבורד | יניב (Claude לא יודע אותה) |
| `DATA_KEY` | מפתח ההצפנה של קובץ התיק | Claude, ועותק נשמר בתיקייה במחשב |

## עדכון מהבנק
מעלים קבצי בנק לשיחה עם Claude. Claude מעדכן את `portfolio.json`, מצפין אותו ל־`portfolio.enc` ודוחף לריפו, והאתר מתעדכן תוך דקה.
